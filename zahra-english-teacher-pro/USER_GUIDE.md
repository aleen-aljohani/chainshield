# User Guide — Zahra Aljehani – English Teacher Pro

A simple, step-by-step guide for everyday use. No technical knowledge needed.

> **There is no login.** The app opens straight to your dashboard. Your data is
> saved automatically in this browser as you work.

---

## Opening the app

- **If it's already running:** open **http://localhost:3000** in your browser.
- **To start it (one time on a computer):** open a terminal in the
  `zahra-english-teacher-pro` folder and run `npm install` once, then
  `npm run dev`. Open the link it shows.

The first thing you see is the **Dashboard** with a welcome message, your class
and grade stats, and quick-action buttons.

---

## 1. Set up your profile (recommended first step)
1. Click **Settings** in the sidebar.
2. Fill in **Teacher name, School, Academic year, Semester, Class names,
   Weekly schedule, Notes**.
3. Changes save automatically. Your name and school appear on printed documents.

## 2. Create a class
1. Go to **Students**.
2. In the **Classes** card, click **Add class**.
3. Enter the class name (e.g. `12-A`), section and year, then **Save**.

## 3. Add students
Any of these work:
- **One at a time:** **Students → Add student**, fill in the name and class, **Save**.
- **Many at once:** **Bulk add** → choose the class → paste one name per line → **Add**.
- **From a file:** **Import CSV** (first column = name, second = number).

> Use **fictional names** for demos. All data stays in your browser only.

## 4. Take attendance
1. Go to **Attendance**.
2. Choose the **class** and **date**.
3. Tap **Present / Absent / Late / Excused** next to each student — or click
   **Mark all present** and adjust. Use **Copy previous** to reuse the last list.
4. Print or export CSV from the top buttons. Attendance saves automatically.

## 5. Enter grades
1. Go to **Grades** and choose a **class**.
2. (Optional) Click **Categories** to edit assessment names, weights and max marks.
3. Type each score in the table. Totals, percentages and letter grades update
   instantly.
   - Leave a cell **blank** for a missing score (counts as 0).
   - Type **EX** to mark a category excused (it's dropped and weights re-balance).
4. **Print** or export **CSV** any time.

## 6. Build a question bank (optional but useful)
1. Go to **Question Bank → Add question**.
2. Choose the type, unit, skill, difficulty and marks; write the question and
   answer. For multiple choice, tick the correct option. **Save**.
3. You can search, filter, duplicate, favourite, import and export questions.

## 7. Create a quiz
1. Go to **Quiz Generator**.
2. Set the title and pick **units**, **skills**, **difficulty** and **number of
   questions**.
3. Click **Random** or **Balanced** to auto-select, or add questions manually
   from the pool. Reorder or remove as needed.
4. Use the **Print & export** buttons for the **Student version**,
   **Teacher version + answer key**, or **Answer sheet**.
5. Click **Save quiz** to keep it in your Printable Resources.

## 8. Create a worksheet or homework
- **Worksheets:** go to **Worksheets**, pick a **template** (Quick Practice, Unit
  Review, etc.) or set it up manually, then print the **student** and **answer
  key** versions.
- **Homework:** go to **Homework**, add details and questions, then print
  student/teacher versions. Mark items done when returned.

## 9. Use revision games in class
1. Go to **Revision Games** and pick a game (Quick-fire, Team Challenge, Spin
   Wheel, Word Scramble, Hangman, Memory Match, Jeopardy).
2. Choose a **unit** to focus the content.
3. Games run on the teacher's screen — **no student devices needed**. Team
   Challenge keeps score with a timer; the teacher can reveal answers.

Need to call on students fairly? Use **Random Picker** (card or wheel mode);
absent students are excluded automatically.

## 10. Plan a lesson
1. Go to **Lesson Planner**.
2. Choose the unit and click **Suggest** to pre-fill a draft structure, then edit.
3. **Save lesson**, and use **Print / Export PDF** for a clean copy. The
   **Weekly** view lists all your plans.

## 11. Print anything (and save as PDF)
Wherever you see a **Print** button, click it. A clean print view opens.
- To get paper: choose your printer.
- To get a **PDF**: in the print dialog choose **"Save as PDF"** as the
  destination. That's your exported file.

Printed documents include your name, school, class, date, unit and total marks
where relevant.

## 12. Back up your data
1. Go to **Backup & Restore**.
2. Click **Download backup**. Keep the `.json` file somewhere safe (this is your
   only copy — the app stores data in this browser only).

## 13. Restore your data
1. Go to **Backup & Restore → Choose backup file**.
2. Select your `.json` backup and confirm. This replaces the current data, so
   back up first if you're unsure.

---

## Tips
- **Dark mode & language:** use the moon icon and the **AR/EN** button in the top
  bar. Arabic switches the whole layout to right-to-left.
- **Search:** the top search box jumps to any section.
- **Reset:** Settings has **Reset demo data** (restore samples) and **Reset entire
  application** (delete everything) — both ask for confirmation.
- **Teacher Assistant** creates quick drafts from your own content. It is **not**
  an AI service; every result is labelled *"Draft for teacher review."*
